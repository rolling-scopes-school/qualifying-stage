# Task PRE-QS-1-1-1: Set up the game repository (10 points)

## Description

Create a GitHub repository for Alchemist's Cauldron with a README file, a .gitignore file, and the initial dependencies needed for the game.

## Acceptance Criteria

- A new repository is created for the game project.
- The README file describes Alchemist's Cauldron, the game goal, and the general structure of the task set.
- A .gitignore file excludes build artifacts, dependencies, and editor files.
- The initial project dependencies are installed and committed.
