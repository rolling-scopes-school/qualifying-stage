# Task PRE-QS-1-2-1: Configure bundler (10 points)

## Description

Set up and configure a bundler for Alchemist's Cauldron, with support for development and production builds.

## Acceptance Criteria

- A bundler is installed and integrated with the project.
- The configuration supports both development and production modes.
- Static assets and TypeScript files can be bundled correctly for the game.
