# Task PRE-QS-1-1-2: Set up folder structure (10 points)

## Description

Set up a clear and organized folder structure for Alchemist's Cauldron so game data, game logic, state, storage, UI, styles, and assets are easy to find and maintain.

## Acceptance Criteria

- The project has a well-defined folder structure for game code and assets.
- Game logic is separated from UI rendering files.
- Shared data, state, storage helpers, and UI components are placed in predictable locations.
- The structure is easy to extend when later stories add gameplay and persistence.

## Reference for Students

An acceptable structure may include folders such as:

- `src/data`
- `src/logic`
- `src/state`
- `src/storage`
- `src/ui`
- `src/styles`
- `src/assets`

The exact names may differ if the structure stays consistent and easy to review.
