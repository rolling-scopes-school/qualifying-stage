# MiniGames Common Scoring Scope: No Pixel Perfect / Layout Match Scoring (Story 3)

These requirements apply to Story 3 cross-check review.

## What is scored in Story 3

- Story 3 focuses on **logic and functionality** described in the Story 3 tasks:
  - backend API integration;
  - loading / error / empty feedback behavior;
  - custom SPA routing, History API, deep links, and URL synchronization;
  - filter / sort / pagination behavior driven by API requests;
  - dialog and edge-case states required by the tasks.

## What is not scored in Story 3

- **Pixel Perfect (PP)**, **strict Figma / mockup layout match** and **HML validation** are **not** scored at this stage.
- Layout, spacing, typography, visual polish, and exact mockup correspondence were evaluated in earlier stories.
- Visual or layout mismatches and HTML validation warnings/errors **should not** be used as a reason to reduce points in Story 3.
