# Task RSS-QS-1-5-2: Auth Dialog Open/Close Animations and Dismiss Logic (10 points)

## Description

Implement auth dialog open/close animations and dismiss behavior.

## Acceptance Criteria

- Dialog opening is animated.
- Dialog closing is animated.
- Closing by clicking on the backdrop is implemented.
- Closing by pressing `Esc` is implemented.
- Closing interactions work consistently from both login and sign-up dialog variants.
- Open/close logic does not break page layout and does not introduce horizontal scrolling.
