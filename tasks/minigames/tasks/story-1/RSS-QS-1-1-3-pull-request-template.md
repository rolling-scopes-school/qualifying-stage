# Task RSS-QS-1-1-3: Create a pull request template (5 points)

## Description

Use the official RS pull request template from the documentation as the required base. Students should not create a fully custom template from scratch. The PR description may be extended with additional sections, but the official base structure should be preserved. This helps standardize pull request descriptions and makes it easier to review the purpose and rationale of each proposed change.

## Acceptance Criteria

- The PR description is based on the official RS template from the documentation: <https://rs.school/docs/mentoring/pull-request-review-process#pull-request-requirements-pr>.
- Additional manually added sections are allowed if they do not remove the required base sections.
- The final PR submitted for review matches the required template structure.
