# Task RSS-QS-1-5-1: Auth Dialog Trigger, Position, and Backdrop (10 points)

## Description

Implement the auth dialog trigger, positioning, and backdrop for the unauthenticated user state.

## Acceptance Criteria

- Clicking `Login / Sign up` in the desktop header opens the auth dialog.
- Clicking `Login / Sign up` in the mobile menu opens the same auth dialog and closes the mobile menu at the same time.
- The dialog appears centered in the viewport.
- A dimmed backdrop is rendered under the dialog (color and implementation details are chosen by the student).
