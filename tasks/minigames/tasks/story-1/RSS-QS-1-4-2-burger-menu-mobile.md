# Task RSS-QS-1-4-2: Mobile Burger Menu (25 points)

## Description

Implement the mobile navigation menu that appears at tablet and smaller breakpoints (≤ 768px).  
The menu is triggered by a burger button and covers the full available screen space. Only the unauthenticated user variant is implemented at this stage.

## Acceptance Criteria

- The section is implemented in full compliance with the project's key layout requirements described in [MiniGames Common Layout Requirements](../../common-layout-requirements.md). This is a mandatory criterion.
- A burger menu button appears at tablet width (≤ 768px) and is hidden on desktop.
- Clicking the burger button opens the full-screen mobile navigation menu.
- The opening transition is animated smoothly. The specific animation style is left to the student's discretion.
- The burger button transforms into a close (×) button when the menu is open; the transformation itself (icon change and any color shift) is animated smoothly.
- The mobile menu occupies the full available screen area and is laid out responsively according to the mockup.
- Navigation links point to the Home page.
- Buttons inside the menu open the Auth dialog.
- Closing by clicking the close (×) button inside the dialog is implemented.
- Closing by pressing `Esc` is implemented.
- Closing the menu is animated smoothly; the animation style is at the student's discretion.
- No horizontal scrollbar appears at any point during the open or close animation.
- Only the unauthenticated user variant is required at this stage.
