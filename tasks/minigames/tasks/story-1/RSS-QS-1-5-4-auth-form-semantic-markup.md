# Task RSS-QS-1-5-4: Auth Form Markup and Input Types (10 points)

## Description

Implement the semantic login and registration form markup with correctly typed input fields.

## Acceptance Criteria

- Input fields are implemented according to the mockup for both login and registration variants.
- Correct input types are used (`email`, `password`, and other appropriate types where needed).
- Input visual states are styled according to the style guide (default, focus, and other required states from the mockup), except for validation error states, which will be implemented later as part of form validation.
