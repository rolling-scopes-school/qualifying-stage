# Task RSS-QS-1-5-3: Login/Sign-up Switcher and Block Transitions (10 points)

## Description

Implement the Login/Registration switcher and animated block transitions inside the auth dialog.

## Acceptance Criteria

- A switcher/tabs control is present for `Login` and `Registration`.
- Active/inactive switcher states are visually distinct and styled according to the design style guide.
- Clicking the inactive option switches the auth block.
- Switching between blocks is animated.
- Inline links `Register` and `Login` inside the form also trigger the same block switch behavior.
- Switching logic does not require page reload and keeps the dialog open.
