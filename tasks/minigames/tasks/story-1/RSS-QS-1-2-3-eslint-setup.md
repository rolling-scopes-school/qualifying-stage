# Task RSS-QS-1-2-3: Set up ESLint (5 points)

## Description

Set up ESLint to enforce consistent coding styles and identify potential tasks in the codebase.

## Acceptance Criteria

- ESLint is set up and integrated into the project.
- ESLint uses [TypeScript](https://typescript-eslint.io/getting-started) support and the [Unicorn](https://www.npmjs.com/package/eslint-plugin-unicorn) style guide.
- ESLint configuration enables `noInlineConfig: true`.
- ESLint enables and enforces the `no-explicit-any` rule.
- Students may adjust specific ESLint rules for development convenience, as long as these changes do not conflict with the task requirements or penalties.
