# Task RSS-QS-1-4-1: Site Header Layout (15 points)

## Description

Implement the site header according to the Figma mockup for the unauthenticated user state only.  
The header should match the mockup at all three target breakpoints (375, 768, 1920) and resize fluidly between them without horizontal overflow or layout breakage.

## Acceptance Criteria

- The section is implemented in full compliance with the project's key layout requirements described in [MiniGames Common Layout Requirements](../../common-layout-requirements.md). This is a mandatory criterion.
- Only the unauthenticated user variant is implemented at this stage.
- Navigation links point to the Home page.
- The sign-in button opens the Auth dialog.
