# Task RSS-QS-2-2-1: Game Details Dialog — Trigger, Position, and Backdrop (10 points)

## Description

Implement the trigger, positioning, and backdrop for the Game Details dialog.

## Acceptance Criteria

- Clicking any `Details` button on a game card in the Library opens the Game Details dialog.
- The dialog appears centered in the viewport.
- A dimmed backdrop is rendered behind the dialog, consistent with the Auth dialog backdrop used in Story 1.
