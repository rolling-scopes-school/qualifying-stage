# Task RSS-QS-2-2-2: Game Details Dialog — Open/Close Animations and Dismiss Behavior (10 points)

## Description

Implement animated open/close behavior and dismiss interactions for the Game Details dialog.

## Acceptance Criteria

- Dialog opening is animated.
- Dialog closing is animated.
- Closing by clicking the close button inside the dialog is implemented.
- Closing by clicking the backdrop is implemented.
- Closing by pressing `Esc` is implemented.
- Opening and closing the dialog does not break page layout and does not introduce horizontal scrolling.
