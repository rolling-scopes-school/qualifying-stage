# Task RSS-QS-2-1-2: Mobile Burger Menu (5 points)

## Description

Implement the mobile navigation menu for the Library page. Use [Story 1](../story-1/RSS-QS-1-4-2-burger-menu-mobile.md) as the source of truth for the mobile menu layout, semantics, responsiveness, and interaction states. The same component should be reused on both pages instead of being duplicated.

## Acceptance Criteria

- Follow the mobile menu requirements defined in [Story 1](../story-1/RSS-QS-1-4-2-burger-menu-mobile.md).
- Navigation and link behavior follow [MiniGames Common SPA Navigation Requirements (Story 2)](common-spa-navigation-requirements.md). This is a mandatory criterion.
- The mobile menu is shared by both pages and is not duplicated in the codebase.
