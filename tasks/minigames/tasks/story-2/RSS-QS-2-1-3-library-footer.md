# Task RSS-QS-2-1-3: Footer Layout (5 points)

## Description

Implement the site footer according to the Figma mockup.
Use [Story 1](../story-1/RSS-QS-1-4-7-footer.md) as the source of truth for the footer layout, semantics, responsiveness, and interaction states. The same component should be reused on both pages instead of being duplicated.

## Acceptance Criteria

- Follow the footer requirements defined in [Story 1](../story-1/RSS-QS-1-4-7-footer.md).
- Navigation and link behavior follow [MiniGames Common SPA Navigation Requirements (Story 2)](common-spa-navigation-requirements.md). This is a mandatory criterion.
- The footer is shared by both pages and is not duplicated in the codebase.
