# Task RSS-QS-2-1-3: Footer Layout (5 points)

## Description

Implement the site footer according to the Figma mockup.
Use [Story 1](../story-1/RSS-QS-1-4-7.md) as the source of truth for the footer layout, semantics, responsiveness, and interaction states. The same component should be reused on both pages instead of being duplicated.

## Acceptance Criteria

- Follow the footer requirements defined in [Story 1](../story-1/RSS-QS-1-4-7.md).
- The footer is shared by both pages and is not duplicated in the codebase.
- Navigation links that lead to the Library page should use SPA navigation and should not trigger a full page reload.
